# Harazi Global Trading Website v2

Upload all files at the root of `harazigroup/haraziglobal` (not the ZIP itself or a nested folder). Netlify: branch `main`, blank build command, publish directory `.`.

## Before launch
- Netlify Dashboard > Forms > Enable form detection, then redeploy and test an inquiry; configure email notifications.
- Review all legal pages with qualified counsel, verify company records and privacy notices.
- Review brand and image rights and any licensing claims.
- Confirm domain DNS, HTTPS, business email and access controls.
- The logo is a cropped derivative of the approved supplied logo; inspect it before launch.

Do not upload API keys or private company documents to the public repository.
